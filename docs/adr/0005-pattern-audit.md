# ADR: Үлгілер аудиті және бас тартылған үлгілер

- **Мәртебе:** Қабылданды (M1–M3)
- **Шешім:** Singleton мен Mediator қолданылмайды.
- **Қарастырылған балама:** Барлық паттернді міндетті түрде қосу.
- **Негіздеме / салдар:** Singleton жасырын ортақ күй тудырады; Mediator қажетсіз байланыс қабатын қосар еді.
