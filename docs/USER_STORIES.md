# M1 — 10 user stories / acceptance criteria

1. **Дәрігерлер тізімі:** әкімші емханада барлық дәрігерлерді және мамандығын көре алады.
2. **Слоттар:** әр дәрігер үшін уақыты және AVAILABLE/RESERVED күйі көрсетіледі.
3. **Жазылу:** пациент аты мен бос слот ID-ін енгізгенде бірегей жазылу ID беріледі.
4. **Қайталама брондау:** бір слотқа екі пациент қатар жазыла алмайды.
5. **Валидация:** бос пациент аты немесе белгісіз слот қатесі шығарылады.
6. **Бас тарту:** жазылу жойылғанда слот қайта босайды.
7. **Undo:** соңғы бас тартуды кері қайтарғанда жазылу мен слот қалпына келеді.
8. **Еске салу:** жазылу немесе бас тарту оқиғасында хабарлама шлюзі шақырылады.
9. **Кезек экраны:** тек белсенді жазылулар реттеліп, билеттері көрсетіледі.
10. **Рөлдер:** пациент барлық жазылуларды көрмейді, ресепшн көреді, тек ADMIN бас тарта алады.

Критерийлер `ClinicPatternsTest` және `App` демонстрациясында ішінара/толық тексеріледі. M3 деңгейі үшін in-memory жеткілікті.
